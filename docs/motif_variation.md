# 主導動機與變奏：用同一段旋律說不同的故事（Leitmotif）

在電影配樂、遊戲原聲帶與古典交響樂中，最打動人心的往往不是堆砌幾十首完全不同的歌，而是**「用同一個旋律動機，穿透主角的一生」**。

這種作曲手法被稱為**主導動機（Leitmotif）**——就像《星際大戰》裡達斯·維達的主題、《魔戒》裡的夏爾主題，或是久石讓為宮崎駿電影所寫的主旋律。動機就像主角的名字，無論世界如何更迭、命運如何轉折，只要這個旋律響起，聽眾就能瞬間連結起所有的情感與回憶。

然而，現有的純音訊黑盒子 AI（如 Suno、Udio）每次生成都是全新的不可控隨機波形，根本無法做到「維持同一條動機，但在不同場景演繹不同情緒」。而在 TMD 與文字型 AI（LLM）的協作體系中，這項專業作曲家的核心武器，你動動鍵盤就能輕鬆實現。

---

## 1. 人與 AI 的真正分工：靈魂歸於人類，苦工交給 AI

在動機變奏的過程中，很多人會問：「既然 AI 這麼厲害，那音樂創作裡人類還剩下什麼？」

答案非常明確：**人類負責「意義」與「靈魂」，AI 負責「數學」與「體力苦工」**。

| 比較維度 | 人類創作者（導演 / 靈魂） | AI Agent（配器助理 / 樂理計算機） |
| :--- | :--- | :--- |
| **核心職責** | 捕捉真正動人的旋律動機、決定曲風與情感故事 | 承擔繁重的作曲苦工、聲部安排與對位計算 |
| **具體任務** | • 決定「這段旋律代表哪個角色或命運」<br>• 掌握全曲的高潮、起伏與戲劇張力<br>• 終審驗收聽感與美學品味 | • 四部和聲（SATB）與嚴格對位法計算<br>• 避免聲部衝突與平行五度/八度<br>• 快速配器（弦樂、和弦、貝斯、打擊樂）<br>• 精準小節時值與節奏網格轉換 |

* **人類該做的事（思考與審美）**：
  - **動機賦予意義**：這串音符到底代表「童年的故鄉」、「主角心中的創傷」，還是「命運的預兆」？
  - **決定戲劇張力**：在此時此刻，主角是憤怒、心碎、還是釋懷？該轉入小調還是拉長時值？
  - 這種對**人類生命經驗、情感共鳴與敘事節奏**的感知，是統計模型永遠無法替代的。

* **AI 該做的事（繁瑣計算與配器苦工）**：
  - 計算大提琴與低音管之間的四部和聲（SATB）聲部導進（Voice Leading）。
  - 檢查和弦組成音有沒有衝突、避免平行五度或八度。
  - 將 4 拍的旋律等比切分成十六分音符並排入打擊樂鼓點。
  - 這些在傳統作曲系需要苦練數年的**「樂理計算苦工」**，正是大語言模型最擅長、最能秒級交付的事情。

**人類動腦決定「講什麼故事」，AI 動筆完成「音符計算」**，這才是最理想的人機協作型態。

## 2. 原型：我們的核心動機（The Motif）

假設我們隨意哼出了一段只有 4 個音符的極簡動機（4/4 拍，C 大調）：

```tmd
/* 核心動機：童年約定 */
Motif {
    <4*>
    1 2 3 5 | 3 - - - |
}
```

這個旋律單純、乾淨。接下來，我們將示範如何**音符一個字不變（或僅做微調），只透過變換「節奏、和弦、配器與大小調」**，讓這段旋律在四個截然不同的場景中說出完全不同的故事！

## 3. 四種場景變奏示範（複製即可在 TMD Studio 試聽）

### 場景 A：【純真童年】（陽光、跳躍、草地奔跑）
- **情緒設定**：無憂無慮、純真回憶、充滿陽光與微風。
- **變奏手法**：
  - 維持原本明亮的大調。
  - 網格切換為 `<8*>`，加入休止符讓音符跳躍（斷奏感 Staccato）。
  - 配器選用清脆的木琴／鐘琴（`Glockenspiel`）與木吉他（`AcousticGuitar`）簡單乾淨的 `[1] - [4] -` 進行。
- **你可以這樣下 Prompt 給 AI**：
  - **白話版（不懂樂理直接用）**：
    > 「這是我全曲的核心旋律：`1 2 3 5 | 3 - - -`。我想把它當作主角小時候回憶的配樂，聽起來要有『陽光、草地上奔跑、無憂無慮』的感覺，請幫我寫一個叫 `Childhood` 的段落，用清脆可愛的樂器（像鐵琴或木吉他），節奏輕快一點跳躍一點。」
  - **專業製作人版（精準控制技術參數）**：
    > 「這是我全曲的核心動機：`1 2 3 5 | 3 - - -`。請幫我為『純真童年』場景寫一個段落 `Childhood`：保持大調明亮感，將節奏網格細分為 `<8*>` 斷奏跳躍感，主奏樂器使用清脆的 `Glockenspiel`（鐵琴/鐘琴），並加上木吉他 `AcousticGuitar` 輕柔的民謠和弦伴奏。」

```tmd
Childhood:Glockenspiel@|0|{
    <8*>
    1 0 2 0 3 0 5 0 | 3 - 0 0 0 0 0 0 |
}

Childhood:AcousticGuitar@|0|{
    <4*>
    [1] - [4] - | [1] - - - |
}
```

### 場景 B：【生離死別】（哀傷、小調、雨中淚水）
- **情緒設定**：主角遭遇重大打擊，看著泛黃的照片走在雨中，同一個回憶湧上心頭，但人事已非。
- **變奏手法**：
  - **平行小調轉化（Minor Modal Shift）**：將大調的 `3`（Mi）降半音變成小調音 `3,`（降 Mi）。
  - 將力度降為弱奏 `{p}`，時值拉長。
  - 配器改為深沉哀傷的大提琴（`Cello`）獨奏，伴奏換上暗淡的小調和弦 `[1m] - [6,m] -`。
- **你可以這樣下 Prompt 給 AI**：
  - **白話版（不懂樂理直接用）**：
    > 「請把我的核心旋律 `1 2 3 5 | 3 - - -` 改成全劇最催淚、最心碎的場景 `Tragedy`。聽起來要像『主角在雨中哭泣、心碎失去最愛的人』，請幫我轉成悲傷的小調，速度放慢，用很會哭泣的弦樂（像大提琴）拉出長音，加上緩慢憂鬱的鋼琴伴奏。」
  - **專業製作人版（精準控制技術參數）**：
    > 「現在劇情來到最悲傷的『生離死別』場景。請把核心動機 `1 2 3 5 | 3 - - -` 改編成極度傷感的段落 `Tragedy`：將三音改為降號 `3,` 轉化為平行小調，加入弱音記號 `{p}`，由大提琴 `Cello` 緩慢拉出長音，鋼琴 `Piano` 彈奏稀疏低沉的小調和弦，表現雨中哭泣的心碎感。」

```tmd
Tragedy:Cello@|0|{
    <4*>
    {p} 1 2 3, 5 | 3, - - - |
}

Tragedy:Piano@|0|{
    <2*>
    [1m] - [6,m] - | [1m] - - - |
}
```

### 場景 C：【絕境反擊】（熱血、重金屬戰鬥、拔劍出鞘）
- **情緒設定**：主角在絕境中站起，心中的信念化為怒火，在戰場上發起最後的反衝鋒。
- **變奏手法**：
  - 網格細分到十六分音符 `<16*>`，每個音重複演奏形成激進的行進律動（Machine-gun staccato）。
  - 全力強奏 `{ff}`。
  - 配器換上宏大的銅管齊鳴（`Brass`）、雙大鼓重金屬鼓點（`Drums`）以及震撼低頻的定音鼓（`Timpani[pitchMode=fixed]`）。
- **你可以這樣下 Prompt 給 AI**：
  - **白話版（不懂樂理直接用）**：
    > 「請把我的核心旋律 `1 2 3 5 | 3 - - -` 改編成超熱血的大決戰段落 `Battle`！情緒是『主角在絕境中爬起來、拔劍出鞘發動最後反衝鋒』，聽起來要像好萊塢動作大片或重金屬樂，節奏要極度緊湊，加入震撼的鼓點、銅管齊奏和定音鼓轟鳴！」
  - **專業製作人版（精準控制技術參數）**：
    > 「現在主角在絕境中拔劍反擊！請將核心動機 `1 2 3 5 | 3 - - -` 變奏為震撼的熱血戰鬥段落 `Battle`：切換為 `<16*>` 網格，讓銅管 `Brass` 以機關槍般的十六分音符連續吐音強奏 `{ff}`，並加入雙大鼓激烈的重金屬鼓點 `Drums`，以及鎖定音高的定音鼓 `Timpani[pitchMode=fixed]` 轟鳴。」

```tmd
Battle:Brass@|0|{
    <16*>
    {ff} 1-1- 2-2- 3-3- 5-5- | 3--- ---- ---- ---- |
}

Battle:Timpani[pitchMode=fixed]@|0|{
    <16*>
    1__-0- 1__-0- 1__-0- 1__-0- | 1__--- ---- ---- ---- |
}

Battle:Drums@|0|{
    <16*>
    B-X- S-X- B-B- S-X- | B--- ---- ---- ---- |
}
```

### 場景 D：【深空漫遊 / 孤寂異星】（迷幻、神秘、時間靜止）
- **情緒設定**：主角漂浮在無垠深空看著藍色母星，充滿敬畏、未知與無邊的孤寂。
- **變奏手法**：
  - **時值擴展（Augmentation）**：將音符時值拉長至 `<2*>` 二分音符甚至全音符，營造失重慢動作感。
  - 將音高提升至高八度（`^`）。
  - 和弦換上懸浮感極強的掛留和弦（`[Csus2]`、`[Dsus4]`）與合成器長音襯底（`SynthPad`）。
- **你可以這樣下 Prompt 給 AI**：
  - **白話版（不懂樂理直接用）**：
    > 「請把我的核心旋律 `1 2 3 5 | 3 - - -` 改編成太空科幻風格的段落 `Space`。想像主角一個人漂浮在浩瀚黑暗的宇宙裡看著地球，聽起來要有『失重、慢動作、空靈、孤寂但又很宏偉』的感覺，把旋律放得很慢很高音，背景要有像星雲一樣飄浮的合成器長音。」
  - **專業製作人版（精準控制技術參數）**：
    > 「主角漂浮在無垠太空凝視地球。請將核心動機改編成科幻迷幻風格的 `Space` 段落：使用時值擴展手法將音符拉長為二分音符 `<2*>`，移至高八度 `1^ 2^ 3^ 5^`，由空靈的長笛 `Flute` 演奏；背景加上無節奏敲擊的環境合成器長音 `SynthPad`，使用 `[Csus2]` 等掛留和弦營造無重力的懸浮感。」

```tmd
Space:Flute@|0|{
    <2*>
    1^ - 2^ - | 3^ - 5^ - | 3^ - - - |
}

Space:SynthPad@|0|{
    <1*>
    [Csus2] | [Dsus4] | [Csus2] - |
}
```

## 4. 作曲家的「五大變奏工具箱」

當你指揮 AI 幫你做變奏時，你可以使用以下 5 個經典作曲技巧：

| 技巧名稱 | 概念說明 | 適合的情緒色彩 |
| :--- | :--- | :--- |
| **1. 調性色彩轉換 (Modal Shift)** | 將大調音（3, 6, 7）降半音變成小調音（3,, 6,, 7,）。 | 從陽光變憂鬱、從歡樂變遺憾。 |
| **2. 時值伸縮 (Augmentation / Diminution)** | **放大**：把四分音符變二分音符（慢動作）；<br>**縮小**：把四分音符變八分音符（快進）。 | 放大產生崇高、史詩、深空感；<br>縮小產生急迫、追逐、緊張感。 |
| **3. 節奏重組 (Re-groove)** | 將直線拍子改為三拍子華爾滋 `<3/4>`、放克切分音或三連音 `%(---)`。 | 改變音樂的肢體律動感（舞會、狂歡）。 |
| **4. 配器換裝 (Re-orchestration)** | 音符完全不變，只換樂器（如八音盒 ➔ 大提琴 ➔ 法國號 ➔ 電吉他）。 | 角色心境的蛻變、時間與空間的流逝。 |
| **5. 逆行與倒影 (Retrograde & Inversion)** | **逆行**：旋律倒著吹；<br>**倒影**：原本往上爬的音階改為往下跳。 | 命運的逆轉、黑暗人格或宿敵反派的登場。 |

## 5. 指揮 AI 進行動機變奏的提示詞（Prompt 範例）

你可以直接將以下 Prompt 複製並微調後發送給你的 Chat AI：

> 「這是我全曲的核心動機：`1 2 3 5 | 3 - - -`（4/4 拍，速度 80 BPM）。
> 
> 請保持這段旋律的骨架，為我生成三個截然不同情緒場景的 TMD 段落：
> 1. **【回憶殺】**：改編為小調（降三音 `3,`），速度放慢至 60 BPM，由 `Violin`（小提琴）與 `Piano` 演奏，加入弱音記號 `{p}`。
> 2. **【戰場追逐】**：速度提升至 138 BPM，使用 `<16*>` 網格與短促音符，配器加入 `Brass`、`Bass` 與急促的 `Drums`。
> 3. **【凱旋榮耀】**：使用全管弦樂齊奏（Tutti），音符提升一個八度 `1^ 2^ 3^ 5^`，加入強奏記號 `{ff}` 與定音鼓 `Timpani[pitchMode=fixed]` 轟鳴。
> 
> 請直接輸出符合 TMD 規格的代碼。」

## 6. 下一步：將變奏串接成完整史詩

當你利用動機變奏產生了多個性格迥異的場景後，接下來只要在 TMD 的播放流程（`->`）中，運用速度切換 `{!=...}` 與轉調 `{?+...}` 將它們按劇情順序串接起來，就是一首結構縝密、耐人尋味的大型作品！

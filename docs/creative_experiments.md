# 更多奇思妙想

使用 TMD 與 AI 創作時，若一時沒有明確的旋律動機，也可以嘗試將日常數字、文字或結構映射為音樂素材。

將非音樂資訊編碼為音樂動機並非新概念：
- **巴哈（J.S. Bach）** 曾將自己名字拼寫為德語音名 **$B^\flat - A - C - B^\natural$**（降 B - A - C - 還原 B），置入《賦格的藝術》中作為主題。
- **莫札特** 設計過「擲骰子音樂遊戲（Musikalisches Würfelspiel）」，透過骰子點數與對照表拼接小節來組合成小步舞曲。
- **約翰·凱吉（John Cage）** 曾利用《易經》六十四卦與天文圖表決定音高與長度。

在 TMD 中，你可以將日常數列或文字概念作為動機輸入給 AI，由模型依據樂理規則完成調性化、聲部安排與對位。

## 靈感一：生日與日期

每組數字序列都可以轉化為旋律動機。

例如：`1998 年 5 月 27 日` ➔ 取出數字序列 `1 9 9 8 0 5 2 7`。

### 音樂映射方式
- `1` 為根音 Do。
- `9` 可視為高八度 Re（`2'`）。
- `8` 視為高八度 Do（`1'`）。
- `0` 作為休止符。
- `5 2 7` 形成三和弦分解音。

### 給 AI 的提示詞（Prompt）

```markdown
我的生日是 1998 年 5 月 27 日（數字序列：1 9 9 8 0 5 2 7）。
請扮演浪漫主義時期的作曲家（如蕭邦），幫我用 TMD 語法寫一首約 16 小節的鋼琴華爾滋小品《Birthday Waltz》。

創作要求：
1. 拍號為 3/4 拍，速度約 130 bpm。
2. 右手主旋律：以數字「1 2' 1' 0 5 2 7」作為貫穿全曲的核心主題動機。
3. 左手伴奏：使用經典華爾滋的「低音單音 + 兩拍和弦跳進」（Oom-pah-pah 節奏）。
4. 全曲共 16 小節，請嚴格計算每小節剛好 3 拍，輸出可直接在 TMD Studio 試聽的完整樂譜。
```

## 靈感二：將你的「英文名字」密碼化，譜寫個人專屬主題曲

想為自己、伴侶或朋友寫一首有神秘彩蛋的歌嗎？最經典的玩法就是像巴哈一樣，把英文字母轉化為音符！

### 字母音名映射法

英文字母中本來就含有音名（A, B, C, D, E, F, G），其餘字母只要依序循環對照即可：

- **A ➔ 6 (La)**, **B ➔ 7 (Si)**, **C ➔ 1 (Do)**, **D ➔ 2 (Re)**, **E ➔ 3 (Mi)**, **F ➔ 4 (Fa)**, **G ➔ 5 (Sol)**
- **H ➔ 6**, **I ➔ 7**, **J ➔ 1**, **K ➔ 2** ... 依此類推。

例如名字 **`ALICE`**：

- `A` ➔ 6
- `L` ➔ 3
- `I` ➔ 7
- `C` ➔ 1
- `E` ➔ 3
- 萃取出專屬動機：**`6 3 7 1 3`**（帶有一種空靈、童話般的吉卜力冒險感）！

### 給 AI 的提示詞（Prompt）

```markdown
我想為名字「ALICE」寫一首曲子。透過字母音名映射，ALICE 轉化出的音符動機是：
6 3 7 1 3 (La - Mi - Si - Do - Mi)。

請用 TMD 語法，為這個動機寫一首時長約 16 小節的木管與鋼琴重奏小品《Song for Alice》：
1. 長笛先吹奏溫柔的動機原型「6 3 7 1 3」。
2. 隨後由鋼琴接過動機，展開八分音符的流暢琶音伴奏。
3. 氛圍請設定為宮崎駿/久石讓風格的溫暖療癒感。
4. 請確保每小節拍數精準符合 4/4 拍，可直接在 TMD Studio 播放。
```

## 靈感三：讀一首五言絕句，讓字聲平仄變成旋律

中文本身就是一種自帶音樂性的「聲調語言」（Tonal Language）！詩詞的平仄與字音起伏，天生就是現成的旋律走向：

- **平聲（一聲、二聲）**：音調平直或微升，可映射為**長音**或**三和弦平穩音（1, 3, 5）**。
- **仄聲（三聲、四聲、入聲）**：音調轉折或陡降，可映射為**跳進音（4, 7）**或**短音/切分**。

例如王維的名句：**「空山新雨後，天氣晚來秋」**

- 字聲起伏：平平平仄仄，平仄仄平平。
- 只要讓 AI 依照這段詩詞的意境與聲韻，它就能寫出極具古風文人氣息的五聲音階小品！

### 給 AI 的提示詞（Prompt）

```markdown
請根據王維的《山居秋暝》首句「空山新雨後，天氣晚來秋」寫一首國風室內樂小品。

創作要求：
1. 聲韻映射：依照漢字聲調的平仄起伏，設計出帶有禪意的五聲音階（宮商角徵羽：1 2 3 5 6）主旋律。
2. 配器：
   - 竹笛（或古琴/二胡音色）：緩慢吟唱詩句主題。
   - 鋼琴/木琴：以清脆的高音模仿空山雨滴落下的清澈聲響。
3. 請用 TMD 語法輸出 16 小節樂譜，保持 4/4 拍拍數對齊。
```

## 靈感四：演算法與資料結構

也可以嘗試將電腦科學或數學中的結構作為動機：

### RSA 演算法概念曲
RSA 加密利用質數乘積與模逆元特性：
- **質數 $p$ 與 $q$**：兩條獨立、長度互質的旋律線。
- **模數 $N = p \times q$**：兩聲部合流為和弦柱式。
- **加密 $C \equiv M^e \pmod N$**：旋律經過模運算音高轉換與細分時值展開。
- **私鑰解密**：低音聲部導入原主題，恢復最初的旋律動機。

```markdown
請用 TMD 語法為我寫一首時長約 16 小節的四重奏小品《RSA: The Asymmetric Key》。

音樂結構：
1. 【質數主題】（第 1-4 小節）：
   - V1（質數 p）：7 拍不對稱節奏單音旋律。
   - V2（質數 q）：11 拍節奏交錯進入。
2. 【公鑰生成】（第 5-8 小節）：
   - 兩軌聲部合流為 4/4 拍大調和弦柱式（N = p * q）。
3. 【模冪加密】（第 9-12 小節）：
   - 主題動機（1 3 5 3）被拆解為十六分音符 <16*> 琶音與半音階升降（^, _）。
4. 【私鑰回歸】（第 13-16 小節）：
   - 大提琴在低音部引導出原本的主題動機，聲部收斂至終止式。

請輸出符合 4/4 拍長度的小節檢查規範，每軌標明樂器註解。
```

### Git Commit Hash 雙重賦格
每次 `git commit` 產生的 Hash（如 `b4a1c5` 與 `d8f20e`）由十六進位字元組成：
- 修改前 Hash（`b4a1c5`）作為主題（Subject）。
- 修改後 Hash（`d8f20e`）作為對題（Countersubject）。
- 映射規則：`0` 為休止，`1~7` 為音級，`8~9` 為高八度音，`a~f` 分別對應音名（如 `b` ➔ 7/Si，`c` ➔ 1/Do，`d` ➔ 2/Re，`e` ➔ 3/Mi，`f` ➔ 4/Fa）。

### 地理座標變奏
- 台北座標（北緯 `25.0330`，東經 `121.5654`）。
- 經度數列 `1 2 1 5 6 5 4` 作為五聲音階旋律。
- 緯度數列 `2 5 0 3 3 0` 作為低音聲部節奏。

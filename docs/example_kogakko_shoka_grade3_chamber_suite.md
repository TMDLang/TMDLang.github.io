# 範例：《公學校唱歌》第三學年組曲

由於 TMD 是純文字格式，只要輕鬆組合個別的 TMD 的檔案，並且讓 AI 撰寫過場，就可以產生組曲形式的作品。

《公學校唱歌》是臺灣總督府印製的唱歌課教材，第一版為1934年3月13日發行第一版，至1942年已為第12版發行。在這個範例中，我們擷取了《公學校唱歌》第三學年的前五首歌曲，組合成一首組曲，並且在最後使用五首歌的旋律組合成一段賦格。

# 範例：交響詩—宗治的 1945

《宗治的 1945》是在開發 TMD 相關工具時，透過 TMD 語法，與 Antigravity 中的 Gemini 合作創作的交響詩。以作者自己的家族故事為題材，講述從 1945 年到 2026 年之間的故事，總共分為三個樂章，全長約 25 分鐘，當中也使用了其他範例中的素材，包括 [Legacy](example_legacy.md) 與[新一軍軍歌](example_new_first_army.md)—以短篇的 TMD 檔案，組合出更完整的故事。

### 回憶的主題

使用 [Legacy](example_legacy.md) 的部分旋律，代表開啟了一段回憶之門。在第二樂章與第三樂章中，也都會以回憶的主題開場。在定音鼓的響聲之後，故事正式開始。

### 宗治的漂流—韶關、乳源、八步

楊宗治、號本農，廣東中山沙溪鎮人，民國四年生，在家中排行老四，也是家中的老么—在他出生隔年，父親死於討伐廣東軍閥龍濟光的戰爭中。

民國二十三年前往廣州就讀中國新聞學院，民國二十六年學校毀於日軍戰火中，他也和許多許多廣州居民一樣，隨著廣東省政府，前往韶關，因為在學校中學過電報（當時記者透過電報發稿），他首先在韶關的民防組織擔任發報員，又在遷往韶關的中山大學擔任行政人員，接著去了韶關附近的乳源縣政府糧食科。隨著日軍發動一號作戰，韶關被攻破，他與妻兒—在戰爭期間他成了家，並且誕下二子—一路向西避難，到了廣西八步。那年宗治三十歲。

民國三十四年，戰爭突然結束，他才與家人搭船，順著西江而下，回到廣州。這一段故事中，演奏的是宗治的主題—宗治主題前半句取自廣東經典戲曲《帝女花》的「落花滿天蔽月光」 ，後半句則是原創旋律，代表宗治雖然出身廣東，但是有半生不在廣東。

### 廣州城

在廣州城，演奏的是新一軍軍歌。

民國三十四年八月日軍投降後，九月新一軍從廣西進入廣州，九月初接受日本受降，逐一接收日本軍事設施與武器裝備，管理戰俘以防止譁變，此時廣州的實際控制者便是新一軍。宗治首先在中華路（現在的解放東路）安定下來，要找戰後的新工作，他原本將履歷投到廣東省政府，但新一軍的長官一次拜訪廣東省政府，就把所有知識分子的履歷全部帶走。

過兩天，就通知宗治去新一軍報到。原本演奏的新一軍軍歌，也切到了宗治的主題—宗治換下長袍，穿上了美式 M43 制服，肩膀上掛上了藍鷹徽章，以軍中文職人員身分擔任政治部少校新聞官職務。宗治也遇到了那位牽動他整個後半生的長官—那位他在八步時就早早聽聞的戰爭英雄，那位締造仁安羌大捷、又在緬北戰場擊破日軍第十八師團的軍長。聽說，軍長喜歡讀書人，他的軍隊需要讀書人。

### 白雲山下的大象

和新一軍來到廣州的，還有從緬甸戰場帶來的大象。在這裡演奏的是日後木柵動物園開張時的歌曲《快樂天堂》的第一句「大象長長的鼻子正昂揚」。民國三十四年的冬天，新一軍讓日軍戰俘在白雲山下修建新一軍公墓，安葬在緬北戰場上的英勇戰士，這一群大象也安置在白雲山下。

第一樂章的結尾—新一軍、宗治、大象三個主題的旋律線一起出現，整個廣州都洋溢在勝利的氣氛中。宗治相信，他的世界重新開始運作，經歷八年的逃難，他終於獲得可以讓新聞專長學以致用的工作，接下來，也會在廣州安定下來。

### 1946 年三月的黃埔港

宗治眼前是一大群的海上巨獸。管樂器奏出機械的低鳴。

在短短幾個月，他經歷了各種人生至今從未見過的奇觀，他見到一支前所未有、穿著外國制服的中國軍隊，裝備最精銳的槍砲，他現在則要經歷中國迄今最大型的一次海上軍力投放，美方出動了第七艦隊十幾艘大型運輸艦，將新一軍的近四萬、三個師的兵力，從廣州運送到東北—八年抗戰結束，卻是內戰的開始。

幾萬名在熱帶叢林中打了勝仗、從來都只待過內陸的士兵，幾乎都是第一次在海上搭船，在台灣海峽上、東北季風中的顛簸海象中，在充滿機油味的船艙裡，各各都要把膽汁都吐出來，瀰漫著嘔吐物的氣味。宗治想著還在廣州的家人，離開時妻子還挺著肚子，他的三子即將在七月時出生—這孩子日後還會生下一個寫電腦程式的孫子，當然那時候他連什麼是電腦都不知道—但他那時候早在東北戰場，沒辦法在廣州見到孩子的出生。

頂尖的裝備、嚴格的訓練、豐富的實戰、還有讓官兵信服的領導。宗治相信自己身在全中國最精銳的部隊中，不管要去哪，放眼望去，誰能夠擊敗這支鋼鐵雄師？

### 四平街的雪

新一軍從廣州出發，抵達秦皇島，接著投入瀋陽與四平街。新一軍在白茫茫的關外莽原打了幾場勝仗，在清冷而單調的鋼琴聲中，只有定音鼓發出的槍砲聲迴盪。宗治在《華聲報》—是延續新一軍《精忠報》的機關報—擔任記者，將第一線的戰事化為文字，也直接看到戰事帶來怎樣的破壞。

他難得收到了一張從廣州寄來的照片，照片中妻子抱著剛出生的三子，長子次子站在兩旁，來信還寫到，寄一些軍餉回家。

### 長春

民國三十七年，新一軍軍歌的變奏，新一軍在長春退出歷史舞台。在民國三十六年時，東北戰場的指揮權發生爭執，宗治的直屬長官被調離前線，宗治與長官搭著同一班火車離開，如果沒搭上那班火車，宗治也可能會待在長春。

### 漂流的下一站

海洋的主題與《桃花過渡》奏起。宗治離開了冰天雪地，他跟著長官一起調度，重新回到溫暖的南國—但他沒想到他的下一站，其實兩年前還是敵人的領土，滿街都是日式房子，路上到處有人講著日語—但又何妨？兩年前，連廣州都是日軍的領土。

長官在高雄鳳山成立了陸軍訓練處，也蓋了全台灣第一座眷村，宗治也在陸訓處辦理機關報《精忠日報》（後來陸軍《忠誠報》的前身）。妻子排行老七，帶著三個小孩，在八弟的護送下，從廣州先到廈門，再轉往高雄，最後全家在鳳山團聚。八弟後來回到廣東，在台灣期間，曾經還在眷村村口遇過軍長，而這段與台灣的淵源，讓他日後經歷了十六年的勞改。

大象的主題與《桃花過渡》交疊，廣州的大象，也踏上了這塊土地。

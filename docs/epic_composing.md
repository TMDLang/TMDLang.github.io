# 與 AI 協同創作大型音樂作品（分而治之工作流）

創作一首 5～10 分鐘的多樂章管弦樂、影視配樂、概念專輯長篇組曲或複雜的交響金屬作品時，如果試圖用一段簡單的 Prompt 要求 AI「直接寫出一整首宏大的交響樂」，通常只會得到混亂、動機渙散、重複單調或語法錯誤的輸出。

這背後的原因在於大語言模型的**注意力衰減與上下文限制**。TMD 的純文字、模組化架構（Section-Based Chunking）天生就是為**「分而治之（Divide and Conquer）」**而設計的。

本章將帶你走過一套經過實證的「五步大型作品工作流」，讓你能清晰掌握全局架構，並指揮 AI Agent 一步步拼裝出龐大而嚴謹的音樂史詩。

---

## 步驟一：撰寫音樂腳本與場景大綱（Storyboarding & Structure）

在寫出任何音符之前，先像編劇或電影導演一樣，為樂曲規劃「故事腳本」或「情感起伏地圖」。

**你可以先在筆記中寫下這樣的場景大綱**：
- **場景 1：黎明破曉（Dawn / Intro）**：4/4 拍，60 BPM，極簡稀疏的弦樂長音，營造空靈孤寂感。
- **場景 2：英雄啟程（Journey / Theme A）**：進入 80 BPM，單簧管吹出核心主題，節奏帶有行進步伐感。
- **場景 3：風暴來襲（Storm / Tension）**：加速至 132 BPM，切換為小調，低音弦樂快速走音，銅管與定音鼓強烈衝突。
- **場景 4：平靜回憶（Reflection / Theme B）**：放慢至 72 BPM，鋼琴獨奏變奏主題，轉為溫暖大調。
- **場景 5：凱旋終曲（Triumph / Finale）**：重返核心主題，全體管弦樂齊奏（Tutti），轉高半音升華結束。

> **AI 協作技巧**：你可以將你的故事故事背景發給 AI：「我想為一場太空探險寫一首 8 分鐘的組曲，包含起飛、深空漫遊、小行星危機與發現新星球。請幫我規劃包含拍號、建議 BPM、調性走向與樂器編制的 5 個場景大綱。」

---

## 2. 確立核心動機，分別發展各場景的獨立樂段（Atomic Motifs & Scenes）

不要一次寫整首歌！大型作品的精髓在於**「動機統一（Motivic Unity）」**——用同一個 2～4 小節的核心動機貫穿全曲，但賦予它截然不同的性格。

### 2.1 定義你的核心動機（Core Motif）
例如，你隨意哼出了一段 2 小節動機：
```tmd
Motif_Original {
    <4*>
    1 2 3 5 | 6 - 5 - |
}
```

### 2.2 逐個場景讓 AI 延伸與變形
現在，把場景大綱與動機分別交給 AI，一次只專注打磨一個獨立段落：

- **為場景 2（啟程）生成管弦樂段**：
  > **Prompt**：「請使用核心動機 `1 2 3 5 | 6 - 5 -` 作為主題，為『場景 2：英雄啟程』寫一個 8 小節的段落 `journey`。調性為 D 調（`?= D`），速度 80 BPM，由 `Clarinet`（單簧管）主奏，並加上大提琴 `Cello` 的撥弦與長笛 `Flute` 的高音裝飾。」
- **為場景 3（風暴）進行小調逆行變形**：
  > **Prompt**：「現在我們要寫『場景 3：風暴』的段落 `storm`。請將核心動機改編為小調（降三音、降六音），並加快節奏至 `<16*>` 網格，速度切換為 132 BPM。配器包含短促激烈的低音大提琴 `DoubleBass`、定音鼓 `Timpani[pitchMode=fixed]` 與小號 `Trumpet` 齊鳴。」

因為每次只生成一個獨立的 Section（約 8～16 小節），AI 的注意力非常集中，既不會有小節拍數算錯的問題，配器細節也極為豐富。

---

## 3. 讓 AI Agent 彙整全曲時間軸（Macro Assembly）

當各個場景的小樂段都完成後，現在是指揮 AI 將它們拼合成完整作品的時候了。

**你的 Prompt**：
> 「我已經有了 5 個場景的獨立 TMD 段落：`dawn`、`journey`、`storm`、`reflection` 與 `finale`。
> 請將它們彙整進同一個 `::SCORE::` 檔案中，並在樂譜結尾寫出完整的播放順序（`->` 行進），串接起各段落，並在適當位置加入速度變化 `{!=...}`、轉調 `{?+...}` 與強弱記號，輸出整首完整樂譜。」

**AI 組合出的全曲宏觀行進範例**：
```tmd
::SCORE::
** Odyssey: An Epic Suite **
!= 60
?= D
<4/4>

/* [場景 1：黎明破曉] dawn 各軌道定義 ... */
/* [場景 2：英雄啟程] journey 各軌道定義 ... */
/* [場景 3：風暴來襲] storm 各軌道定義 ... */
/* [場景 4：平靜回憶] reflection 各軌道定義 ... */
/* [場景 5：凱旋終曲] finale 各軌道定義 ... */

/* 全曲巨集演奏時間軸 */
-> dawn
-> {!= 80} -> journey
-> {!= 132} -> {?-2} -> storm
-> {!= 72} -> {?+2} -> reflection
-> {!= 96} -> finale -> {?+1} -> finale
->#
```

## 4. 試聽、刪除冗餘與修飾生硬轉場（Audition & Polish）

在將作品帶進 DAW 之前，必須進行**聽覺驗收（Ear Check）**與除錯：

1. **一鍵全曲試聽**：
   - 貼入 **TMD Studio** 點擊 `Play ▶`，或在終端機執行 `tmd my_epic.tmd --play`。
   - 使用 `tmd check my_epic.tmd` 確認全曲幾百個小節沒有任何拍數落差。
   - 使用 `tmd inspect my_epic.tmd` 查看總時長與各段落樂器密度的起伏曲線。
2. **指揮 AI 修飾生硬轉場（Transition Smoothing）**：
   - 如果發現「風暴」直接跳到「平靜」太過突兀，立刻向 AI 下指令：
     > **Prompt**：「`storm` 轉到 `reflection` 的過渡太生硬了。請在兩個段落之間幫我設計一個 2 小節的銜接過渡段落 `storm_outro:Strings@|0|`，讓定音鼓弱化、小提琴拉一條長音高音並加入漸弱記號 `{p}`，自然引出鋼琴獨奏。」
3. **刪除冗餘與精簡結構**：
   - 如果某個段落聽起來拖沓，直接讓 AI 將重複的小節刪除，或調整播放流程：例如把反覆兩次改為只反覆一次 `-> finale ->#`。

## 5. 匯出至 DAW 進行音色代換與後期混音（Production in DAW）

TMD 的任務是幫你在最短時間內搞定**作曲（Melody）、和聲（Harmony）、節奏（Rhythm）與配器架構（Orchestration）**。當骨架與細節在純文字層面都精確無誤後，就可以進入專業音樂製作流程：

```bash
# 匯出 Standard MIDI 檔案
tmd my_epic.tmd -m my_epic.mid

# 或直接匯出 REAPER 專案工程檔
tmd my_epic.tmd -r my_epic.rpp
```

### 在 DAW 中的下一步：
1. **載入工程檔**：在 Logic Pro、Cubase、Ableton Live、FL Studio 或 Studio One 中打開匯出的 MIDI。
2. **軌道自動命名與對齊**：所有音軌（Flute, Clarinet, Violins, Cello, Timpani）與段落小節已經全部對齊就緒。
3. **掛載高品質音色庫**：將預設的 General MIDI 音色替換為頂級虛擬樂器（如 Spitfire Audio、Cinematic Studio Series、EastWest 或 Vienna Symphonic Library）。
4. **繪製表情控制器（CC 控制曲線）**：微調 Modulation（CC1）、Expression（CC11）與力度曲線，為管弦樂注入呼吸感。
5. **混音與母帶後製**：掛上空間殘響（Reverb）、EQ 與壓限器，完成最終成品發行！

## 總結：小型創作 vs. 大型作品的工作心態對比

| 比較維度 | 單曲 / 短動機創作 | 大型作品 / 史詩組曲創作 |
| :--- | :--- | :--- |
| **創作策略** | 直覺哼唱、單一 Prompt 生成 | 先定場景大綱，分而治之，動機變形 |
| **AI 角色** | 陪你找和弦、補配器的小夥伴 | 依照導演劇本負責各幕美術與配樂的執行團隊 |
| **TMD 優勢** | 即時手打、輕量記譜 | 模組化段落隔離錯誤、時間軸巨集宏觀調度 |
| **最終歸宿** | 網頁 Studio 快速試聽匯出 | 匯出 MIDI / REAPER 進入 DAW 進行史詩級混音 |

# 範例：為兒歌譜曲—點蟲蟲

《點蟲蟲》是一首經典的廣東兒歌，是跟孩子玩手指遊戲時常唱的歌曲，遊戲過程大概是大人攤開手掌，讓小孩用手指去「點」大人的掌心，大人說著「點蟲蟲」，接著大人將手掌移開，就說「蟲蟲飛呀」。

在這邊的並不是廣東原本的《點蟲蟲》 （點蟲蟲，蟲蟲飛，飛到荔枝基…），而是廣東家庭到了台灣之後的國語化版本—家中雖然還有廣東人可能會怎麼帶小孩的記憶，但小孩這一輩已經不會講廣東話，所以整首兒歌還是玩點蟲蟲遊戲，但唱詞全變成了國語，故事也大幅簡化。內容只有—「點蟲蟲，蟲蟲飛呀」。

在家中如果有一段給孩子的簡單旋律，也可以透過 TMD 與 AI，為這段旋律編曲。
